# Salon Queue Management System (Moksha Shah)
Live Demo :: https://salon-queue-tau.vercel.app/

Hosted on :: Vercel (frontend) + Render (Backend)
# About
The Salon Queue Management System is a web-based application designed to digitize and simplify the walk-in customer queue management process at a salon.
Instead of customers manually waiting, asking staff about their turn, or standing in a crowded queue, the system allows them to select a service, register themselves, receive a token number, and track their queue status.
The system also helps salon staff manage customers efficiently, while the admin can manage services, stylists, and salon operations.

# Main Objectives
- Reduce confusion and manual queue management.
- Make the customer waiting process more organized.
- Provide customers with token numbers and estimated waiting time.
- Help staff efficiently call, serve, and complete customers.
- Display queue information on a common salon display screen.
- Allow administrators to manage salon services and stylists.
